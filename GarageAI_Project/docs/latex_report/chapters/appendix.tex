\section{Yêu cầu môi trường và Cấu hình biến môi trường (\texttt{.env.example})}

Hệ thống hỗ trợ chạy trực tiếp trên máy trạm (Windows / Linux / macOS với Python 3.10+ và Node.js 20+) hoặc qua Docker Compose. Các biến môi trường chính trong tệp \texttt{GarageAI\_Project/.env.example} gồm:

\begin{lstlisting}[aboveskip=2pt,belowskip=2pt,caption={Cấu hình mẫu tệp .env.example của hệ thống GarageTools AI}]
APP_NAME=GarageTools AI
APP_ENV=development
SECRET_KEY=doi-thanh-mot-chuoi-ngau-nhien-dai-truoc-khi-trien-khai-that
DEBUG=true
SESSION_COOKIE_SECURE=false
DATABASE_PATH=garage.db
AUTO_MIGRATE=true
AI_PROVIDER=mock
AI_API_KEY=
AI_BASE_URL=
AI_MODEL=
AI_TIMEOUT=15
AI_MAX_CONTEXT=6000
\end{lstlisting}

Khi muốn chạy với mô hình ngôn ngữ thật miễn phí của Groq trong tệp \texttt{.env} cục bộ, chỉ cần đặt \texttt{AI\_PROVIDER=groq}, \texttt{AI\_MODEL=openai/gpt-oss-120b} và điền khóa \texttt{AI\_API\_KEY} (hoặc \texttt{GROQ\_API\_KEY}).

\section{Quy trình khởi tạo CSDL, chạy ứng dụng và thực thi kiểm thử}

Thực thi các lệnh sau để khởi tạo cơ sở dữ liệu \texttt{garage.db}, chạy Backend FastAPI, chạy giao diện React 19 và kiểm chứng toàn bộ bộ kiểm thử tự động:

\begin{lstlisting}[aboveskip=2pt,belowskip=2pt,caption={Các lệnh khởi tạo CSDL, chạy hệ thống, kiểm thử 226 ca và sao lưu}]
# 1. Khoi tao CSDL (21 bang, 37 chi muc, 171 dong du lieu mau) va chay Backend
cd GarageAI_Project
pip install -r requirements.txt
python database/init_db.py
python -m uvicorn app.main:app --reload --port 8000

# 2. Chay giao dien React 19 + TanStack Start (tu thu muc frontend/)
cd ../frontend
npm install
npm run dev

# 3. Chay toan bo 226 ca kiem thu tu dong Backend (tu dong dung AI_PROVIDER=mock)
cd ../GarageAI_Project
python -X utf8 tests/run_all.py

# 4. Chay kiem thu Smoke (31 ca), E2E (32 ca) va Sao luu CSDL (tu thu muc goc)
cd ..
.\scripts\smoke.ps1
.\scripts\e2e.ps1
.\scripts\backup.ps1
\end{lstlisting}
